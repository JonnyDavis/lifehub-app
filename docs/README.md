# Docs

These docs are the “source of truth” Codex (and future-you) should read to stay oriented between sessions.

If you only read one thing, start with:
- `context.md`

## What goes where

- `context.md`: current app behavior + repo map (keep this up to date)
- `status.md`: what we’re building next (Now/Next/Later)
- `architecture.md`: high-level system overview
- `data-model.md`: tables/fields we assume in Supabase
- `adr/`: short decision records (the “why”)

## Private notes

Create `docs/_private/` locally for anything you don’t want in a public GitHub repo
(personal data, real dates, screenshots, credentials, etc.). That folder is gitignored.
